## 핵심 역량 요약

HTML, CSS, JavaScript 기반의 시맨틱 마크업과 반응형 웹 구현 경험을 보유하고 있습니다. Material Design 3 가이드라인을 준수하여 5가지 윈도우 사이즈 클래스별 디자인을 Figma로 직접 제작하고 구현했습니다. 디자인 시스템의 컴포넌트가 제공되지 않을 때 직접 구현한 경험이 있으며, 다양한 환경(브라우저, 버전)에서의 호환성을 고려한 개발을 합니다.

## 프로젝트

### hada — 한국어 단어 암기 앱

**기술스택**: TypeScript, Next.js, React, SCSS, Motion, Material Design 3, Figma

**역할**: 기획, UI/UX 디자인, 프론트엔드 전체 구현

**퍼블리싱 관련 성과:**

- **M3 기반 반응형 디자인**: Material Design 3 가이드라인을 준수하여 Figma로 전체 UI를 직접 디자인. 5가지 윈도우 사이즈 클래스(Compact, Medium, Expanded, Large, Extra Large)별 레이아웃 설계 및 구현
- **커스텀 컴포넌트 구현**: M3 웹 컴포넌트가 전부 제공되지 않아 일부 컴포넌트를 직접 구현. 제공되는 컴포넌트는 MUI를 통해 React 환경에 통합
- **SCSS 기반 스타일 관리**: 컴포넌트별 SCSS 모듈로 스타일 분리, 디자인 토큰 활용
- **Motion 애니메이션**: 카드 학습 인터랙션에 Motion(Framer Motion) 적용
- **다국어 지원**: next-i18n을 활용한 국제화 마크업 구조 설계

**회고:** 화면 하나당 5개 사이즈를 디자인하면 작업량이 과도 → 실무에서는 2~3개 브레이크포인트로 충분하다는 판단

### Wordle Decks — 워들 덱 공유 플랫폼

**기술스택**: Next.js, TypeScript

**퍼블리싱 관련 성과:**

- **ISR 기반 OG 메타태그**: 소셜 공유 시 미리보기가 정확히 노출되도록 각 덱 페이지의 메타태그를 정적으로 생성
- **Optimistic UI**: 좋아요 버튼의 즉각적 UI 반응 구현 (서버 응답 대기 없이 UI 먼저 업데이트, 실패 시 롤백)
- **무한 스크롤**: 덱 목록에 무한 스크롤 적용으로 초기 로딩 최적화

### not4k — 4레인 리듬게임

**관련 역량:**

- 게임 UI의 실시간 인터랙션 처리 (노트 낙하 애니메이션, 키 입력 피드백)
- 사용자 입력에 즉각 반응하는 UI 설계

## 웹퍼블리셔 요구 역량 매핑

| 요구사항 | 관련 경험 |
|----------|----------|
| **크로스브라우징** | 엑셀 버전 차이(2019)로 함수가 깨지는 문제를 직접 경험하고 하위호환 함수로 전면 교체. 이 경험에서 체득한 "환경 차이를 먼저 확인하고 호환성을 보장하는" 사고방식을 웹 개발에도 적용. M3 웹 컴포넌트 미지원분을 직접 구현하고 MUI로 통합한 경험 |
| **WAI-ARIA / 접근성** | M3 가이드라인 준수 과정에서 시맨틱 마크업과 ARIA 속성 적용. 카드 학습 인터랙션에서 키보드 네비게이션과 스크린리더 대응 고려 |
| **반응형 레이아웃 트러블슈팅** | 5가지 윈도우 사이즈 클래스(Compact~Extra Large)별 레이아웃을 Figma로 설계하고 구현하면서, 브레이크포인트 간 전환 시 레이아웃이 깨지는 문제 대응. 회고: 5개는 과도하며 2~3개 브레이크포인트가 현실적이라는 판단 |
| **해상도별 UI 문제** | 윈도우 사이즈 클래스별로 컴포넌트 배치·크기·여백이 달라지는 상황에서 디자인 토큰 기반으로 일관성 유지. SCSS 모듈로 사이즈 클래스별 스타일 분리 관리 |

## 웹퍼블리셔 적합성

- **디자인→구현**: Figma에서 직접 디자인하고 코드로 구현하는 전 과정 경험
- **디자인 시스템 이해**: M3 가이드라인 준수, 컴포넌트 규격에 따른 구현
- **반응형 웹**: 5가지 윈도우 사이즈 클래스별 디자인·구현 경험
- **크로스 환경 호환성**: 엑셀 버전 차이에서 체득한 호환성 우선 사고방식을 웹에도 적용
- **CSS 역량**: SCSS 모듈, Tailwind CSS, 디자인 토큰 활용 경험
