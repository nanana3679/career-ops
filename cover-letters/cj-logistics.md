# CJ대한통운 자기소개서 — IT 개발 (일반전형)

## 1. 물류업 선택 이유 및 CJ대한통운 지원 동기 (700자 이내)

모델하우스에서 5개월간 ERP 시스템 운영과 계약서 관리를 담당하며, 현장 운영과 데이터가 분리되어 있을 때 발생하는 비효율을 직접 체감했습니다. 계약서가 어떤 상태인지 파악하려면 실물 박스를 뒤져야 했고, 수기 관리는 바쁜 순간에 반드시 누락이 발생했습니다. 저는 파일명 규칙과 매크로를 활용해 사람이 기록하지 않아도 상태가 자동으로 추적되는 체계를 만들었고, 이 경험에서 현장 프로세스를 기술로 개선하는 일에 강한 흥미를 느꼈습니다.

물류업은 이 경험의 연장선에 있었습니다. 물건의 입고부터 배송까지 모든 단계에서 실시간 추적과 최적화가 필요하고, 현장의 물리적 흐름과 데이터 시스템이 긴밀하게 연결되어야 합니다. 제가 현장에서 느꼈던 '추적 불가능한 것을 추적 가능하게 만드는' 문제의식이 가장 큰 스케일로 존재하는 산업이라고 판단했습니다.

CJ대한통운의 곤지암 메가허브는 하루 175만 건을 자동분류하며, 기존 대비 작업인력 70% 수준에서 처리량은 23% 높였습니다. 매일오네 서비스는 일 2,000만 건의 데이터를 실시간 처리합니다. 이러한 기술이 현장에 닿으려면 현장 사용자가 실제로 쓸 수 있는 운영 도구와 서비스 인터페이스가 필요합니다. 현장에서 직접 시스템을 운영하며 사용자 관점의 문제를 체감한 경험을 바탕으로, 그 접점을 만드는 IT 개발자로 기여하고 싶어 지원했습니다.

## 2. 직무 수행을 위한 노력과 강점 (1000자 이내)

TypeScript, React, Next.js 기반 웹 애플리케이션을 기획부터 구현, 배포까지 수행한 경험이 있습니다.

한국어 단어 암기 앱 'hada'에서 프론트엔드 전체를 담당하며 간격 반복 알고리즘(FSRS)을 통합했습니다. 핵심 설계는 학습 카드의 순서를 결정적으로 보장하는 셔플 알고리즘이었습니다. 같은 날 같은 학습 상태에서는 항상 동일한 순서가 생성되도록 설계했고, 이 하나의 결정이 새로고침 복원을 포함한 여러 파생 문제를 동시에 해결했습니다. 설계 과정에서 데이터 정규화 수준, 추상화 레이어 등 여러 트레이드오프를 경험했고, 회고를 통해 불필요한 복잡도를 줄이는 방향을 체득했습니다.

Wordle 덱 공유 플랫폼에서는 ISR 기반 소셜 미리보기, Optimistic UI 등을 적용하여 기획부터 배포까지 완료했습니다. 배포 후 콜드 스타트 문제를 직접 겪으며, 기술 완성도만으로는 서비스가 성립하지 않는다는 것을 배웠습니다.

두 프로젝트와 5개월간의 모델하우스 현장 경험에서 공통적으로 체득한 것은, 구조를 바꾸지 않는 해결책은 문제를 옮길 뿐이라는 원칙입니다. 물류 IT에서 AI와 자동화 기술이 고도화될수록, 그것을 현장 사용자에게 전달하는 운영 도구와 서비스 인터페이스의 중요성도 커집니다. 현장에서 ERP를 직접 운영하며 '시스템이 왜 현장에서 안 먹히는지'를 체감한 경험과, 웹 서비스를 기획부터 배포까지 수행한 개발 역량이 그 접점에서 강점이 된다고 생각합니다.

## 3. 어려움에도 끝까지 관여한 경험 (700자 이내)

모델하우스 오픈 첫날, 상담 건수 150건을 혼자 처리해야 했습니다. 처음 하는 업무를 실시간으로 입력해야 하는 상황에서 인력 지원을 요청했지만 감당이 되지 않았고, 하루가 끝났을 때 통계는 하나도 맞지 않았습니다. 1시간 동안 수습을 시도했지만 해결되지 않아 저는 퇴근했고, 주임님이 3시간을 더 수습했습니다.

시키지 않은 일이었지만, 다음 날 바로 개선에 착수했습니다. 하나의 표를 단일진실공급원으로 두고 시간별 통계는 함수로 자동 산출되도록 설계했습니다. 오류가 발생하면 즉시 드러나도록 가시화하고, 수기 카운트와 교차검증하는 체계를 도입한 결과 실수가 하루 0~1건으로 감소했습니다.

3개월 차에는 계약서 관리에서 같은 문제가 반복되었습니다. 계약서 상태를 파악하려면 실물이 있을 만한 위치를 직접 뒤져야 했고 최소 30분이 소요되었습니다. 관리자는 수기 기록을 지시했지만, 바쁜 순간에 누락이 발생하는 구조적 한계를 제시하고 파일명 규칙과 매크로 기반의 자동 추적 체계를 대안으로 제안했습니다. 결과물과 함께 제안드렸고, 승인 후 클릭 몇 번으로 전체 계약서 상태를 파악할 수 있는 프로세스로 정착했습니다.

알바 업무의 범위를 넘어서는 일이었지만, 5개월간 문제가 발생할 때마다 구조를 개선하며 현장의 기본 체계로 만들었습니다.
